# Community code of conduct

We want Mewmori's plugin community to be welcoming, practical, and safe.

Be respectful. Discuss ideas and code without personal attacks, harassment, discrimination, or intimidation. Give actionable feedback, assume good faith until evidence suggests otherwise, and respect privacy when sharing logs or screenshots.

Maintainers may edit or remove contributions, comments, or accounts that violate these expectations or put users at risk. Serious or repeated violations may result in a temporary or permanent ban from the project.

Report conduct concerns privately to the repository maintainers. Do not include another person's private information in a public issue.
